# field — SFC 영역운동

SFC 영역협의체(의료 · 통일 · 환경 · 공학)의 홍보물과 모임 스케치를 모으는 홈페이지입니다.

- 홈: https://sfc-movement.github.io/field/
- 영역 방: `/field/<영역>/` (예: `/field/environment/`)
- 게시물: `/field/<영역>/<연-월-이름>/` (예: `/field/environment/2026-11-bookclub/`)

| 영역 | 폴더 |
|---|---|
| 의료 | `medical/` |
| 통일 | `unification/` |
| 환경 | `environment/` |
| 공학 | `engineering/` |

공통 스타일과 로고는 `assets/`에 있습니다.
