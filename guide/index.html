영역장 안내

홈페이지에 글 올리는 방법

양식을 채우고 사진을 끌어다 놓으면, 간사님 승인 뒤 몇 분 안에 페이지가 만들어져요.

준비

GitHub 계정 하나만 있으면 돼요

글은 GitHub이라는 곳의 '이슈' 양식으로 올려요. 계정이 없다면 github.com/signup에서 이메일로 무료 가입해 주세요. 휴대폰에서는 GitHub 앱을 깔면 더 편해요.

01

양식을 골라요

📸 모임 스케치 올리기 📣 모임 홍보 올리기 ✏️ 영역 소개·인사 바꾸기 📖 '영역운동이란?' 글 올리기
  • 스케치: 이미 한 모임의 기록. 카드 여러 장으로 된 페이지가 돼요.
  • 홍보: 앞으로 있을 모임. 모임 날짜가 지나면 자동으로 '지나온 기록'으로 옮겨져요.
  • 영역운동이란?: 영역운동 소개글·강의안. #으로 장을, ##으로 카드를 나눠요.
02

칸을 채우고 사진을 넣어요

사진은 칸 안에 끌어다 놓거나 붙여 넣으면 돼요. 휴대폰에서는 칸을 누른 뒤 아래쪽 클립(📎) 버튼으로 사진을 고르세요.

스케치의 내용 카드는 이렇게 써요. ##으로 시작하는 줄마다 새 카드가 생겨요.

## 창조 세계는 우리의 이해를 넘어선다
하나님은 어떤 것도 똑같이 지으시지 않으셨어요.

> 인상 깊은 문장은 이렇게 인용해요. (p.27)

## 우리가 할 수 있는 일
- 자가용 자제
- 텃밭 가꾸기

빈 줄은 문단 나누기, - 는 목록, **굵게**는 강조예요.

03

제출하면 끝, 승인을 기다려요

맨 아래 Create(또는 Submit new issue)를 누르면 접수돼요. 간사님이 확인하고 승인하면 몇 분 안에 홈페이지에 올라가고, 이슈에 페이지 링크가 담긴 댓글이 달려요. GitHub 알림으로도 받을 수 있어요.

04

고치거나 내리고 싶을 때

  • 고치기: 내가 올린 이슈를 열어 본문 오른쪽 위 ··· → Edit로 고친 뒤, 간사님께 "다시 승인해 주세요"라고 댓글을 남겨요.
  • 내리기: 이슈에 "내려 주세요"라고 댓글을 남기면 간사님이 내려 드려요.

올리기 전에 꼭 확인해요

  1. 공개 웹페이지예요. 전화번호 같은 개인정보는 넣지 말아 주세요. 문의는 인스타그램이나 오픈채팅 링크로요.
  2. 얼굴이 나온 사진은 본인 동의를 받은 것만 올려요.
  3. 책 내용은 짧은 인용만, 나머지는 우리 말로 정리해요.

관리자용: 승인하는 방법
  • 새 이슈가 오면 내용을 확인하고, 오른쪽 Labels에서 승인을 붙이면 자동으로 게시되고 이슈가 닫혀요.
  • 수정 후 다시 게시: 이슈를 다시 열고(Reopen) 승인 라벨을 뗐다가 다시 붙여요.
  • 내리기: 삭제 라벨을 붙여요.
  • 저장소 쓰기 권한이 있는 사람이 붙인 라벨만 처리돼요.
